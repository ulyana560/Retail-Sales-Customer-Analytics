# Excel Data Preparation

This folder contains the data preparation stage of the project.

### What was done

The original dataset was prepared using Excel and Power Query.

The following steps were performed:

* checked and corrected data types;
* checked missing values;
* checked duplicate records;
* checked unusual or inconsistent values;
* validated order and shipping dates;
* created `Shipping Days`;
* created `Year`, `Month`, and `Year-Month` columns.

The prepared dataset will be used for further analysis in PostgreSQL and Power BI.

### Output

The cleaned dataset contains the original sales data with additional fields prepared for further analysis.
